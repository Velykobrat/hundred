# Hundred 1.1.0 — release notes

Hundred 1.1.0 focuses on interface refinement, readability, responsive behavior, and faster interaction with Parts.

## Highlights

- Cleaner structural Part cards with a dedicated utility row and a more readable responsive grid.
- A compact Add Part and Cards/List toolbar, with the mobile floating action retained.
- Temporary status messages that do not shift the page layout.
- Simpler Settings, an accessible guide accordion, and segmented language and theme controls.
- Improved title handling with card clamps, counters, and optional guidance for longer names.
- Refined Hundred branding and category colors across light and dark themes.

The core data model and storage format are unchanged; no migration is required.
